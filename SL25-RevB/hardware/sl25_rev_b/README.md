# SL25 Rev B：中心 RGB 光源 PCB

本版与 `../../enclosure/sl25_traffic_rev_b/` 外壳配套，取代 Rev A 的偏上小灯珠设计。**PCB 正面只有一颗位于几何中心的 WS2812B-V5，其他电子元件和 USB-C 均在背面。** 板框仍为 25×25 mm，双层、1.6 mm 厚，两个 M2 孔的位置保持原接口。

此版灯珠、电阻值、元件安装面和固件灯光控制方式均与 Rev A 不同。制板、买料和装壳应整套使用 Rev B，不能把旧灯珠或旧外壳混入新版。

建议原型制板：FR-4、2 层、1.6 mm、1 oz、常规阻焊。可以选白色阻焊，但混光主要依靠独立白色腔体，不依赖阻焊颜色。元件坐标文件已标明正反面，下单贴片时仍应与预览核对。

布线主宽 0.20 mm，过孔 0.60/0.30 mm；USB4105 定位孔与焊盘的厂家图形存在约 0.194 mm 间距，孔到铜最小规则沿用 0.18 mm。下单前确认制板方支持这一孔铜间距。

## 电路变化

CH552G、USB-C、USBLC6 ESD 保护、独立 5.1k CC 电阻和 USB ISP 触点保持原电路功能。D1 换为 5 V 四脚贴片 WS2812B-V5，内部集成 RGB 驱动。

| 信号 | 连接 |
| --- | --- |
| LED 数据 | CH552G 物理脚 3 / P1.5，经 R3=330Ω 到 D1 DIN |
| DIN 默认电平 | R4=100kΩ 下拉到 GND |
| D1 电源 | 1=+5V，3=GND；C5=100nF 为局部旁路 |
| D1 数据 | 4=DIN，2=DOUT 不连接 |
| USB 数据 | CH552G 12=D+、13=D−，经 USBLC6 保护接 USB-C A/B 对应引脚 |
| V33 | CH552G 16，只接 C2=100nF，不向其他元件供电 |
| RESET | CH552G 6，经 R7=10kΩ 下拉 |
| ISP | JP1 上电时临时通过 R6=10kΩ 将 D+ 拉高，平时断开 |

删除旧 R5 和三路 LED 1k 限流方式；R3、R4 已改作数据信号用。输入 C3 增至 4.7µF，5 V 电源上的外加电容名义总量为 5.0µF，V33 的 100nF 单独计算。不要按旧版的 1k 电阻表装配。

## 固件接口

新灯不接受旧版三路 GPIO PWM。需使用 800 kbit/s 的 24 位 **GRB、最高位先发** 数据；帧间低电平复位应大于 280µs。MCU 应在启动、USB 未配置、USB 挂起及主机命令超时时发送全零关灯帧。初始化 P1.5 为低电平，再启用输出。

数据手册在 12mA 条件下给出各色亮度，RGB 全亮可按约 36mA 加静态电流作初步功耗估算，但这不是整机最大电流保证。实际亮度、USB 功耗描述及挂起电流必须按样板测量确定。建议先从低亮度测试红、绿和红绿混合黄色。

本次交付是 PCB 和机械设计，没有编写或验证固件、USB 枚举和电脑状态采集程序。VID/PID 在固件阶段确定。

## 机械接口

PCB 顶视图坐标：左上角为 (0,0)，X 向右，Y 向下。

| 项目 | 位置或尺寸，mm |
| --- | --- |
| 板框 | 25×25，圆角 1，名义厚度 1.6 |
| D1 封装与光学中心 | **(12.5,12.5)**，正面；焊接方向 180° |
| D1 主体 | 5.4×5.0，厂家高度 1.57±0.05；外壳按板上方 1.7 留量 |
| D1 引脚朝向 | 正视 PCB 时：1 在右下，2 在右上，3 在左上，4 在左下；切角为 3 脚 |
| 安装孔 | H1 (2.7,2.7)，H2 (22.3,2.7)，孔径 2.2 |
| USB-C | 背面，封装原点 (12.5,21.15)，朝板的下边插拔 |
| 背面元件最低点 | 参考 STEP 为板背面下方约 3.395 |

装入外壳后，D1 与 Ø24 mm 灯窗同轴，中心均为外壳正视图 (15,15)。白色混光腔平底压在正面阻焊表面，中心 8×8 mm 缺口让开 LED 及焊盘；不得在正面加装其他元件或留下突起焊料。

## 检查与限制

KiCad ERC、DRC、未连接和原理图一致性检查均通过。关键检查还包括 WS2812B 引脚、GPIO 数据路径、CC 电阻、V33、RESET、ISP、正反安装面、灯珠中心和本地模型路径。参考模型已与外壳做体积干涉检查。

尚未打样、通电、验证 USB 信号完整性或测试光学均匀度。USB 是短走线的全速原型，没有阻抗控制或认证声明。PCB 预览中灯珠顶面颜色来自通用模型，不代表点亮或实物膜片效果。

- [Worldsemi WS2812B-V5 数据手册](https://www.world-semi.co.kr/_files/ugd/89cd03_1023b0e9d135431aa1e6491bfc318112.pdf)，机械及引脚见第 2 页，电气和时序见第 3–4 页；本地副本 `../reference/WS2812B-V5.pdf`。
- [GCT USB4105 厂家图纸](https://gct.co/files/drawings/usb4105.pdf)，本地副本 `../reference/USB4105.pdf`。
- [WCH CH552 数据手册入口](https://www.wch-ic.com/downloads/CH552DS1_PDF.html)，本地副本 `../reference/CH552.pdf`。
- [ST USBLC6-2 数据手册](https://www.st.com/resource/en/datasheet/usblc6-2.pdf)。
- 封装和通用 STEP 模型来自 [KiCad 官方库](https://www.kicad.org/libraries/license/)，适用其库许可及例外。

使用 KiCad 自带 Python 依次运行 `../generate_rev_b.py`、`../route_rev_b.py`、`../finish_board.py 本目录路径`；生成过程覆盖已有新版输出，应先保留自己的手工改动。默认 KiCad 安装于 `E:/Kicard`，其他机器可通过环境变量调整库路径。
